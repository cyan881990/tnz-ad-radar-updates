# TNZ Ad Radar — Windows updates

Official Windows x64 installers for TNZ Ad Radar. This repository contains distribution releases only; the development repository remains private.

Download the latest installer from [Releases](https://github.com/cyan881990/tnz-ad-radar-updates/releases/latest). Verify its SHA-256 with the accompanying `.sha256` file.

From version 1.5.4, update checks and downloads do not require a GitHub account or token. The app asks before installation and waits for scanning to stop. Employee TNZ authentication is still required to use the application.

Installers are currently unsigned. No employee credentials, browser profiles or collected ad data are included.
